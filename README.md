# 🐍 100 Days of Python

This repository documents my progress through the **100 Days of Code: Python** course by Dr. Angela Yu.

I originally started the course in 2025 and worked through a number of the early projects before putting it aside. In August 2026, I decided to pick it back up where I left off and continue the journey.

Rather than using this repository as a collection of every exercise from the course, I want it to document **what I learned, what I built, and how my understanding of Python develops over time**.

## 🎯 Goals

* Strengthen my Python fundamentals
* Become more comfortable solving problems independently
* Practice breaking larger problems into smaller pieces
* Improve my understanding of object-oriented programming
* Build projects that gradually become more complex
* Document not just finished code, but what I learned while building it

## 📚 Learning Progress

### The Beginning — 2025

The first part of the course introduced the foundations of Python through small exercises and increasingly complex projects.

Some of the concepts I practiced included:

* Variables and basic data types
* String manipulation
* Conditional statements
* `for` and `while` loops
* Functions
* Lists
* Randomization
* Debugging
* Breaking problems into smaller steps

One exercise I particularly remember was navigating **Reeborg's World**, where debugging the maze challenge became an exercise in understanding control flow rather than simply getting the robot to the exit.

As the projects became larger, I started working with more complex program structure and game logic.

### Moving Into Larger Projects

Projects such as **Blackjack** introduced problems where several pieces of logic had to work together: drawing cards, calculating scores, handling special cases such as Aces, controlling the dealer, and managing the game loop.

Later, working with Python's Turtle module introduced:

* Coordinates
* Event listeners and keyboard input
* Screen updates and animation
* Object-oriented programming
* Classes and objects
* Game loops
* Collision detection

## 🐍 Snake Game

One of my favorite projects from my first attempt at the course was the **Snake game**.

It was also an important step in understanding how several programming concepts work together in an actual program rather than as isolated exercises.

While working on Snake, I practiced:

* Creating and moving multiple Turtle objects
* Tracking coordinates
* Keyboard controls
* Using `tracer(0)` and manually updating the screen
* Managing the snake through lists
* Detecting collisions
* Creating food and score systems
* Separating responsibilities into classes such as `Snake`, `Food`, and `Scoreboard`

## 🚀 Restart — August 2026

I'm continuing the course from where I previously stopped.

From here onward, I want this repository to serve as an active learning journal. For each project I add, I want to document not only **what the program does**, but also:

* What new concepts were introduced
* What I found difficult
* Problems or bugs I encountered
* How I approached solving them
* Things I would implement differently now
* Additional experiments I made beyond the course requirements
